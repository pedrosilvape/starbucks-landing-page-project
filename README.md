# 🍔 Starbucks Landing Page

Uma landing page responsiva com tema do Starbucks, construída com HTML, CSS e JavaScript.

## 🌐 Visualize o projeto:

**[Ver Projeto Online](https://pedrosilvape.github.io/starbucks-landing-page-project/)**

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Marcação semântica
- **CSS3**: Estilização
- **JavaScript**: Funcionalidade interativa
- **Font Awesome**: Ícones
- **Google Fonts**: Fontes

## 🚀 Como Começar

1. Clone ou baixe os arquivos do projeto
2. Abra o arquivo `index.html` no seu navegador
